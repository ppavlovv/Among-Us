# Katki Rehberi

1. Depoyu fork edin ve degisikliginiz icin ayri bir dal acin.
2. Kisisel dosya yollari, oyun dosyalari, loglar, oda kodlari ve derlenmis
   EXE/DLL dosyalari eklemeyin.
3. Degisikligi desteklenen oyun surumunde test edin.
4. `SandboxMod/Tests/PolicyTests.csproj` testlerini calistirin.
5. Pull request aciklamasinda davranis degisikligini ve test sonucunu yazin.

Online odalarda baska oyunculari etkileyen ozellikler, hile korumasi atlatma,
hesap ele gecirme, veri toplama veya uzaktan komut altyapisi kabul edilmez.
