# Guvenlik Politikasi

Bir guvenlik acigi bulursaniz hesap bilgisi, oda kodu, log veya baska kisisel
veri eklemeden GitHub Security Advisory acin. Depo yayina alindiktan sonra
`Security > Advisories > New draft security advisory` yolunu kullanin.

Genel hata raporlari icin GitHub Issues veya topluluk baglantilari kullanilabilir.
Guvenlik aciklarini herkese acik Discord kanallarinda paylasmayin.

Yalnizca en son kaynak surumu desteklenir. Ucuncu taraflardan alinmis EXE/DLL
dosyalari bu projenin guvenlik kapsaminda degildir.
